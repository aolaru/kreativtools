PDF to Images help and limits

PDF to Images help and limits

Each selected page becomes one picture, including its visible text and graphics. This renders complete pages; it does not extract the original embedded image files. Higher resolution creates more pixels, not new detail.

PNG is lossless; JPG trades some detail for smaller files. Images have a white background. The chosen DPI controls raster dimensions; the downloaded image's encoding may report a different print-resolution tag. Use the pixel dimensions shown in the preview when placing the image in another app.

Exports lose selectable text, PDF form behavior, accessibility tags, and verifiable digital signatures. Keep the source PDF. File processing stays in the browser, and no PDF metadata is copied into the newly rendered image.

Encrypted PDFs are not supported. Export up to 50 pages and 100 MB of images per batch, with a maximum of 16 million pixels and 8192 pixels per side on each page. Reduce DPI or use fewer pages if a file is too large.

For page rotation or reordering, use PDF Page Organizer. For the reverse conversion, use Image to PDF.
