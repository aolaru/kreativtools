Image to PDF guide

Use this tool when a screenshot, photo, scan, or design image needs to become a simple one-page PDF.

Best uses

  • Turn a receipt, invoice image, screenshot, or single-page scan into a PDF.
  • Create a quick PDF upload when a form does not accept image files.
  • Add page sizing and margins before sending a visual document.

How it works

The browser draws the uploaded image into the selected page size and margins, then generates the PDF directly in the page.

Supported files

Upload common browser-readable image files such as JPG, PNG, GIF, or WebP. The output is a one-page PDF.

Privacy and limits

The image stays in your browser. Very large source images can create large PDFs, and text inside the image remains a flat image, not selectable text.

Common issues

  • If the PDF is too large, resize or compress the image before creating the PDF.
  • If the page framing looks wrong, adjust page size, orientation, or margin before downloading.
  • For multiple images or pages, create separate PDFs first and then merge them.

Next step
