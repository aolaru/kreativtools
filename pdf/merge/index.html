    PDF merge guide

    PDF merge guide

    Use this tool when the main job is building one ordered document from several PDF files, and you want to confirm the queue before exporting.

    Best uses

    • Combine contracts, invoices, reports, or receipts into one review package.
    • Join exported sections of a report after checking the final order.
    • Build a single handoff PDF from several source files without installing PDF software.

    How it works

    Add two or more PDFs, review the queue, move files up or down, remove mistakes, then merge. The output follows the visible queue exactly.

    Supported files

    The inputs must be PDF files. Password-protected, encrypted, or damaged PDFs may not merge because the browser cannot read their pages safely.

    Privacy and limits

    Files are read and merged in the browser session. For each file, leave the pages field blank for all pages, or enter ranges such as 1, 3-5. Select Remove metadata to clean the merged PDF before download; your source files are unchanged. Very large documents or many high-resolution scanned PDFs can hit browser memory limits.

    Common issues

    • Merge does not automatically compress the output or repair broken PDF files.
    • Review the queue before exporting because page order follows file order.
    • If you only need selected pages, split the source PDF first.

    Next step

    If the merged file is too large to send comfortably, continue with PDF Compress. If you need the reverse workflow later, use PDF Split.
