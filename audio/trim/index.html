Audio trim guide

Use this tool when the source audio is useful but only one section should be delivered, shared, or processed further.

Best uses

  • Remove silence, setup chatter, or extra recording time from the start and end of a clip.
  • Export a short quote, voice note, interview answer, sound effect, or music sample.
  • Create a cleaner segment before converting the file to a smaller MP3 handoff.

How it works

The browser decodes the uploaded audio, renders only the selected start and end range, then exports the trimmed segment as a WAV file.

Supported files

Upload common browser-readable audio files such as WAV, MP3, M4A, OGG, or FLAC. Actual format support depends on your browser.

Privacy and limits

The audio stays in your browser. Very long recordings can use a lot of memory, and WAV exports may be larger than the original compressed file.

Common issues

  • The end time must be after the start time before an export can be generated.
  • Compressed inputs are exported as WAV, so use Audio to MP3 afterward if file size matters.
  • If the browser cannot decode the source file, convert it to WAV or MP3 first.

Next step

Need a smaller delivery file? Use Audio to MP3. For repeat handoffs, use the Audio Delivery workflow.

Before you export audio

Audio jobs are easier when trimming, volume changes, and format conversion happen in a clear order. Trim unwanted sections before converting, check loudness before sharing, and choose MP3 only when a smaller delivery file matters more than keeping WAV quality.

For spoken audio, clarity and steady volume matter more than aggressive compression. For samples or music ideas, keep a higher-quality source and export a lighter copy for sharing. If the result sounds harsh, reduce gain or bitrate changes and export again from the original file.

  • Preview the selected section before downloading.
  • Avoid very high gain settings that can clip speech or music.
  • Keep WAV for editing and MP3 for lightweight sharing.

After downloading the result, open it once before using it in a client send, upload form, website, or archive. This final check catches format support issues, unexpected file size changes, missing characters, clipped media, or page-order mistakes while the original file is still available.

If the output will be reused, note the settings that produced it. That makes the next export easier to repeat and reduces guesswork when another file needs the same treatment.
