Image resize and convert guide

Image resize and convert guide

Use this tool when the image is the right file but needs exact dimensions, a different output format, or a quick one-page PDF export.

Best uses

  • Resize a homepage, ecommerce, portfolio, or social image to exact pixel dimensions.
  • Convert one uploaded asset into JPG, PNG, WebP, or AVIF without opening design software.
  • Export a single image as a simple PDF when a form or handoff requires PDF instead of image.

How it works

The browser loads the image, keeps the aspect ratio when selected, draws the target size to canvas, then exports the format or PDF you choose.

Supported files

Input can include JPG, PNG, WebP, AVIF, GIF, BMP, and TIFF when the browser can decode them. Output options are JPG, PNG, WebP, AVIF, or PDF.

Privacy and limits

The image is processed locally in your browser. Extremely large files can exceed canvas or memory limits, so resize in smaller steps if needed.

Common issues

  • If the image stretches, keep aspect ratio enabled or enter only one dimension first.
  • If the file is still heavy after resizing, export WebP or continue with compression.
  • If the crop is wrong, crop first so the resize does not preserve unwanted edges.

Next step

If the file is still too heavy, continue with Image Compress. If the framing needs work first, use Image Crop.
