Image resize and convert guide

Use this tool when the image is the right file but needs exact dimensions, a different output format, or a quick one-page PDF export.

Best uses

  • Resize a homepage, ecommerce, portfolio, or social image to exact pixel dimensions.
  • Convert one uploaded asset into JPG, PNG, WebP, or AVIF without opening design software.
  • Export a single image as a simple PDF when a form or handoff requires PDF instead of image.

How it works

The browser loads the image, keeps the aspect ratio when selected, draws the target size to canvas, then exports the format or PDF you choose.

Supported files

Input can include JPG, PNG, WebP, AVIF, GIF, BMP, and TIFF when the browser can decode them. Output options are JPG, PNG, WebP, AVIF, or PDF.

Privacy and limits

The image is processed locally in your browser. Extremely large files can exceed canvas or memory limits, so resize in smaller steps if needed.

Common issues

  • If the image stretches, keep aspect ratio enabled or enter only one dimension first.
  • If the file is still heavy after resizing, export WebP or continue with compression.
  • If the crop is wrong, crop first so the resize does not preserve unwanted edges.

Next step

If the file is still too heavy, continue with Image Compress. If the framing needs work first, use Image Crop.

When this becomes repeat work

Need crop, resize, and compression in one flow?

Image Resize stays useful for one direct change. Use Image Prep when the same delivery job needs framing, exact dimensions, format choice, and saved defaults together.

Before you export an image

Check framing first, then dimensions, then file weight. A smaller image is not automatically better if it loses the detail the destination needs. For product images, thumbnails, and social posts, compare the exported file at the size where it will actually appear.

If an upload limit is the main problem, reduce dimensions before lowering quality. If visual clarity is the main problem, keep the quality higher and change the format only after reviewing the preview. For ecommerce and portfolio images, consistent dimensions usually matter as much as raw file size.

  • Crop before resizing when the frame is wrong.
  • Resize before compressing when the source is much larger than needed.
  • Keep an original copy so you can re-export with a different format or quality setting.

After downloading the result, open it once before using it in a client send, upload form, website, or archive. This final check catches format support issues, unexpected file size changes, missing characters, clipped media, or page-order mistakes while the original file is still available.

If the output will be reused, note the settings that produced it. That makes the next export easier to repeat and reduces guesswork when another file needs the same treatment.
