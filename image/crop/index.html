What to do next

After cropping, use Image Compress to reduce the file weight, or switch to Image Resize & Convert if you still need exact output dimensions.

Quick FAQ

  • Should I crop before resizing? Yes, if the framing is wrong. Crop first so the final dimensions apply to the part of the image that actually matters.
  • Which aspect ratio should I choose? Use `1:1` for square cards, `4:5` for portrait posts, and `16:9` for wide preview layouts.
  • Can I export to web-friendly formats? Yes. The cropped result can be downloaded as JPG, PNG, or WebP.
