Image compression guide

Image compression guide

Use this tool when the picture already has the right crop and dimensions, but the file is too heavy for a website, CMS, email, marketplace, or client handoff.

Best uses

  • Reduce product images before uploading to Shopify, WooCommerce, or a CMS.
  • Make screenshots and blog graphics lighter for email, chat, and support tickets.
  • Export WebP or AVIF versions when the destination supports modern image formats.

How it works

The browser decodes the image, draws it to a canvas, then exports a new JPG, WebP, AVIF, or PNG using the quality and format you choose.

Supported formats

Input depends on browser support and can include JPG, PNG, WebP, AVIF, GIF, BMP, and TIFF. Output options are JPG, WebP, AVIF, and PNG.

Privacy and limits

Files are processed in this browser session. Very large images can still be limited by device memory, browser decoding support, or canvas export support.

Common issues

  • PNG is lossless, so it may not shrink much compared with JPG, WebP, or AVIF.
  • Transparent images should usually stay PNG or WebP to avoid a solid background.
  • If the image is physically too large, resize first instead of only lowering quality.

Next step

If the dimensions are still too large, use Image Resize & Convert. If the framing is wrong, use Image Crop before compressing again.

Example image compression jobs

Example image compression jobs

Store product photo: resize the image to the storefront display size first, then compress to WebP or JPG so the product page loads faster without wasting pixels.

Support screenshot: keep the screenshot readable, lower quality only enough to fit chat or email limits, and avoid PNG if the file is mostly photographic.

Blog graphic: compress after the final crop and dimensions are set. If the image still feels too heavy, reduce physical dimensions before lowering quality again.
