# Security Policy

## Reporting a vulnerability

Do not open a public issue for a suspected security problem. Email [hello@madebykreativ.com](mailto:hello@madebykreativ.com) with:

- A short description of the issue and its potential impact.
- The affected page or file path.
- Steps to reproduce, a proof of concept, or a safe test file where possible.
- Any suggested mitigation.

Reports are acknowledged as soon as practical. The maintainer will assess the issue, coordinate a fix when needed, and credit the reporter only with their permission.

## Scope

The most relevant reports involve client-side file handling, dependency integrity, cross-site scripting, open redirects, unsafe downloads, and accidental collection or transmission of user files. The project has no user accounts or intended server-side file uploads.

## Supported versions

Only the current `main` branch and the deployed static site are maintained. Older forks and historical deployments may not receive fixes.
