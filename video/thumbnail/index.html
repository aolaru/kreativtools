Video thumbnail guide

Use this tool to capture a still frame from a video and export it as a thumbnail image.

Best uses

  • Create a quick cover image for a video upload, page section, or preview card.
  • Capture a visual reference frame for feedback, support, or documentation.
  • Export PNG or JPG thumbnails without opening a video editor.

How it works

The browser loads the video, seeks to the selected playback position, draws that frame to a canvas, then exports the canvas as an image.

Supported files

Upload videos your browser can play. Thumbnails can be exported as PNG or JPG, with quality control available for JPG output.

Privacy and limits

The video stays in your browser. The captured image matches the current frame, so move the playback position before capture if needed.

Common issues

  • Wait for the frame to appear in the preview before capturing.
  • If the video cannot be decoded by the browser, no thumbnail can be captured.
  • JPG creates smaller files, while PNG is better for crisp interface captures.

Next step

Need to trim the video first? Use Video Trim. Need to reduce the thumbnail file size? Use Image Compress.

Before you export video

Browser video support depends on the file format, codec, and device. Short clips are usually easier to process than long recordings. For email or social delivery, trim first, capture the needed thumbnail, then convert only when the destination requires a different format.

When a clip is for review, speed and compatibility usually matter more than maximum quality. When a clip is for publishing, check the playback target and keep the original source available. Browser exports are convenient for quick jobs, but long or high-resolution videos can be memory-heavy.

  • Use short source files when possible.
  • Check the start and end frame before downloading.
  • Keep the original video if the browser export needs to be adjusted.

After downloading the result, open it once before using it in a client send, upload form, website, or archive. This final check catches format support issues, unexpected file size changes, missing characters, clipped media, or page-order mistakes while the original file is still available.

If the output will be reused, note the settings that produced it. That makes the next export easier to repeat and reduces guesswork when another file needs the same treatment.
