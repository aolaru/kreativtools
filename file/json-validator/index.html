JSON validator guide

How to use it

Paste JSON or open a file, then select Validate. Format adds indentation; Minify removes unnecessary whitespace. Copy or download the result when ready.

What is checked

This checks JSON syntax, not a JSON Schema or whether the data is correct for a particular application. Objects, arrays, strings, numbers, booleans, and null are accepted.

Common errors

Use double quotes around keys and strings, remove trailing commas, and escape special characters inside strings. Error details depend on your browser.

Privacy and limits

JSON is processed in your browser and is not uploaded. Input is limited to 2 MB; deeply nested documents may be too large to format. Keep a copy of your original file.

Convert data

Convert an array of objects with JSON to CSV, or create JSON with CSV to JSON.
