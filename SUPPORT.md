# Support

## Using the public site

For a broken tool, browser compatibility issue, or documentation error, open a GitHub issue using the available templates. Include the affected URL, browser and version, expected result, actual result, and safe reproduction steps.

For a private question, email [hello@madebykreativ.com](mailto:hello@madebykreativ.com). Do not send sensitive documents or real client files.

## Security issues

Use the private reporting process in [SECURITY.md](SECURITY.md), not public issues.

## Project scope

Kreativ Tools is in maintenance mode. Support is best-effort and focused on keeping the existing browser tools safe and usable. New tool requests, monetization requests, analytics, and server-side processing are outside the default scope.
